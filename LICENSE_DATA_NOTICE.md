# Dataset licensing: unresolved documentary conflict

The current UCI catalog for Dataset 240 states **CC BY 4.0**: https://archive.ics.uci.edu/dataset/240/human+activity+recognition+using+smartphones .
The README included in historically mirrored UCI HAR archives says **"Any commercial use is prohibited."**
These statements conflict. This repository does not resolve this legal ambiguity. Data is not redistributed. For commercial exploitation seek clarification from rights holders/institution.
The software in this repository is original research code; the source dataset retains its own terms. Credit the dataset authors and report changes as required by the catalog.
