Download only from the primary UCI source (Dataset 240). Either run `har-shift acquire --root .` when online, or manually put the original ZIP under `data/raw/uci_har_official.zip`. `har-shift audit --root .` checks ZIP SHA-256, CRC, entry safety, shapes, labels and subject disjointness. Large dataset files are deliberately not committed.
Official URL: https://archive.ics.uci.edu/static/public/240/human%2Bactivity%2Brecognition%2Busing%2Bsmartphones.zip
Do not confuse the 58.2 MB catalog size with extracted size. The audit records actual sizes and checksums on your machine.
